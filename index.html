How To Use

Player Guide

  1. Login: Click "Login with Discord" to connect your account
  2. Link Profile: Select your team and player name when prompted
  3. Mark Availability: For each week, click "I Can Play" or "Can't Make It"
  4. Check Lobbies: See which teams are in your lobby each week
  5. Get Notified: Watch for Discord announcements about upcoming weeks

Admin Guide

  1. Import Teams: Upload team rosters from the spreadsheet
  2. Import Schedule: Set up weekly lobbies and matchups
  3. Announce Weeks: Post to Discord asking players to mark availability
  4. Set Webhook: Configure Discord webhook for announcements
  5. Manage Admins: Grant admin access to other users
